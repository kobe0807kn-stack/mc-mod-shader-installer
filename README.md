# mc-mod-shader-installer

一个给 AI Agent 用的技能（Skill）：自动找到 Minecraft 游戏目录，把模组或光影装进去，带下载校验、冲突预检和一键撤回。

用户只需要说两件事：游戏版本号，和想要的模组或光影。剩下的找目录、认加载器、下载、校验、备份、安装、记账，全部自动完成。

- 单文件，除 Python 3.8+ 标准库外无任何依赖
- 跨平台：Windows / macOS / Linux
- 优先使用 Modrinth 官方源，下载后校验 SHA-1 与 SHA-512
- 安装前自动快照，支持三级撤回
- 只增不改：存档、配置和你原有的模组一个字都不动

## 一、用途

装模组时经常卡住的几件事，这个技能都接了过去：

| 常见痛点 | 本技能的做法 |
| --- | --- |
| 找不到 `.minecraft` 在哪 | 自动扫描常见路径 + 启动器 exe 旁边的目录 |
| 模组放进去不生效 | 自动判断「版本隔离」，放到正确的 `mods` 目录 |
| 下载到假文件 / 损坏文件 | 比对官方 SHA-1 和 SHA-512，不一致直接丢弃 |
| 装了之后游戏黑屏 | 校验加载器匹配、版本区间匹配，缺前置自动补齐 |
| 装坏了没法回退 | 安装前快照，支持撤销最近一次 / 本次全部 / 整目录还原 |

它不做下载站，也不做启动器，只负责把下载、校验、安装、回滚串成一条流程。

## 二、使用方法

### 2.1 作为 Agent 技能使用（推荐）

把 `SKILL.md` 放到你的 Agent 技能目录下（例如 `~/.workbuddy-ai/skills/mc-mod-shader-installer/SKILL.md`），之后直接对 Agent 说：

> 帮我装一下 1.21.1 的 Xaero's Minimap，链接：https://modrinth.com/mod/xaeros-minimap

Agent 会走完整个流程，并回报装到了哪里、校验结果如何、怎么撤回。

### 2.2 你需要提供什么

只有两样：

1. 游戏版本号，你实际在玩的那个，比如 `1.21.1`、`26.2`
2. 模组或光影的链接或名字，Modrinth / CurseForge / mcmod.cn / 直链都可以

不需要提供游戏文件夹路径，技能会自己找。

### 2.3 手动运行检测脚本

如果只想确认游戏目录在哪，可以单独运行附录 B.1 的脚本：

```bash
python detect.py 1.21.1
```

输出是一段 JSON，包含：

- 找到的所有 Minecraft 根目录
- 每个根目录下已有的版本文件夹
- 匹配到的版本
- 是否开启版本隔离（及判断依据）
- 检测到的模组加载器
- 最终应使用的 `mods_dir` 与 `shaderpacks_dir`

### 2.4 光影的额外步骤

光影包本身不会生效，得先有光影加载器：

- Iris（Fabric / NeoForge），推荐
- Oculus（Forge）
- OptiFine

技能检测到缺失时会一并装上 Iris。光影包装好后，在游戏里的 选项 → 视频设置 → 光影 中选择。

### 2.5 装完之后

**先重启启动器，再启动游戏。** 启动器只在启动时扫描 `mods` 文件夹，不重启看不到新模组。

## 三、适用场景

适合：

- 你想装一个模组或光影，但完全不知道游戏目录在哪
- 你用的是 PCL2 / HMCL / BakaXL 等中文启动器，模组放进去不生效
- 你同时装了多个启动器或多个实例，不确定该往哪个文件夹放
- 你担心下载到损坏或被篡改的文件
- 你想装之前先备份，出问题能一键撤回
- 你在给别的玩家写教程，需要一份准确、可复用的安装流程

不适合：

- 原版（vanilla）环境下装模组：模组需要加载器，技能会明确告知，不会强行安装
- 想给别人的机器装：技能只操作本机
- 管理整合包（modpack）：建议用启动器自带的导入功能
- 修改存档、配置、`options.txt`：这些技能明确不碰

## 四、注意事项

1. 技能只增不改，但确实会在游戏目录里写东西。它会在游戏根目录下创建 `_mod_tool/` 用于暂存、备份和记账，同名的模组文件会被移到 `_mod_tool/replaced/` 而不是直接覆盖。如果你不想让它在游戏目录里写文件，提前说一声。

2. 装完先重启启动器，否则新模组不会出现。这是「装了没用」最常见的原因。

3. 技能不会为你的版本强行安装不匹配的构建。如果 Modrinth 上没有对应版本，它会如实告知并给出邻近版本建议。强行跨大版本安装是启动黑屏的头号原因。

4. 哈希校验是硬门槛，校验不通过的文件会被丢弃、不会安装。直链下载没有官方哈希，技能会在报告里说明这一点。

5. NeoForge 的模组不能装进 Fabric 环境。技能会读 `mods.toml` / `fabric.mod.json` 判断，不匹配就停下并说明。

6. 只有光影包、没有 Iris / Oculus / OptiFine 是不会生效的。光影会改变画面并影响帧率，所以技能会明确告知「我会一并装上 Iris」，不会悄悄装。

7. 如果检测到多个候选安装，技能会列出启动器名、版本文件夹和最近游玩时间，让你选一个。这是它唯一允许的额外提问。

8. `saves/`、`config/`、`options.txt`、`servers.dat` 和启动器自身文件，技能全部不改动。

9. 下载走 Modrinth 公开 API，需要能访问 `api.modrinth.com`。请求要带 `User-Agent` 头，否则会被 403 拒绝。

10. 当你只说「随便找个好的」时，技能只推荐下载量 ≥ 10,000 且 24 个月内有更新的项目。低于这个门槛的，只在你点名时才会装。

11. 撤销最近一次和撤销本次全部不会误删你手动改过的文件（哈希变了会跳过）。整目录还原会先把当前状态再备份一份，所以撤回本身也可以撤回。

## 五、仓库结构

```
mc-mod-shader-installer/
├── README.md     ← 本文件：用途、使用方法、适用场景、注意事项
├── SKILL.md      ← 技能正文：完整流程、硬性规则、附录脚本
└── LICENSE       ← MIT
```

`SKILL.md` 里有三个附录：

- Appendix A：中文完整流程，可直接给中文玩家看
- Appendix B：可直接复制使用的 Python 脚本，覆盖目录探测、下载校验、版本区间判断
- Appendix C：速查表，各类路径与参数
